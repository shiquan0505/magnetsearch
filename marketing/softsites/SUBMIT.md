# 软件站收录：投哪儿、要什么材料、注意什么

## 一、先准备「素材包」（所有站点通用）
| 材料 | 规格 | 说明 |
|---|---|---|
| 应用图标 | 1024×1024 PNG（透明底另存一份） | 从 Assets.car 导出或重画 |
| 截图 | 3–5 张 1600×1000 PNG | 搜索框/结果列表/设置-授权栏 |
| 一句话简介 | ≤ 30 字 | 「macOS 上的磁力搜索助手，多源聚合，中英文容错」 |
| 详细简介 | 200–400 字 | 见 `../github/README.md` 前两段 |
| 版本号/更新时间 | 3.4 / 2026-11-26 | |
| 安装包 | MagnetSearch-3.4.pkg / .dmg | 放自己站点的下载页链接更好（带统计） |
| 系统要求 | macOS 12.0+，Intel / Apple 芯片（Rosetta 2） | |
| 官网/下载页 | https://121.196.163.89.sslip.io/download | 有自有域名后换掉 |
| 隐私说明 | 一句话：不收集任何用户数据；搜索请求只发往本机 127.0.0.1:3333 | 国内站常要求 |

## 二、国内站（多数对"磁力/种子"类敏感，先问再投）
| 站点 | 提交入口 | 备注 |
|---|---|---|
| 软天空 | `ruan.qq.com` 网页底部「软件提交」 | 审核较松，需注册 |
| 历趣 | `liqucn.com` → 底部「软件提交」 | 需企业/个人资料 |
| PC6 / 华军 / 下载吧 | 站点底部「发布软件」 | 人工审核，可能要求独家/付费 |
| 太平洋下载 | `dl.pconline.com.cn` → 软件提交 | 审核严 |

⚠️ 这类站普遍不接受 BT/磁力工具，或要求「付费置顶」。被拒是常态，别在这上面花太多时间。

## 三、海外站（对这类工具宽容，且被 Google/Bing 收录，反过来带权重）
| 站点 | 入口 | 备注 |
|---|---|---|
| MacUpdate | `macupdate.com/developers` | 需注册开发者账号，免费 |
| AlternativeTo | `alternativeto.net/manage-app/` | 可自建条目，收录快，dofollow |
| Softpedia | `softpedia.com/webmaster/` | 审核几天 |
| Hacker News / Reddit r/macapps | 直接发帖 | 只发一次，别刷；r/macapps 效果最好 |

## 四、投放时的三个铁律
1. **一稿一改**：每个站的简介都要重写几句，别复制粘贴（搜索引擎判定为低质重复）。
2. **链接指向落地页**，不要直接指向 pkg 文件（落地页有统计、有介绍、能被收录）。
3. **别买链接、别用站群**：百度对买卖链接打击很重，短期上去也会被清。自然外链每周 2–3 条就够。
