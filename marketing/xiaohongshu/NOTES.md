# 小红书：3 篇笔记 + 合规话术

## 平台规则要点
- **不能放站外链接**（正文、评论都不行），只能靠：主页简介、私信自动回复、置顶评论引导「主页」
- 不能出现"下载""破解""免费资源"等词，用「工具」「客户端」「效率」替代
- 图片里不要出现二维码（会被判营销）

## 笔记 1：痛点型（最容易爆）
**标题**：`Mac 找资源，被广告逼疯后我自己写了个工具`
**正文**：
```
之前每次找片：打开搜索站 → 关三个广告 → 复制磁力 → 发现中文名搜不到 → 再想英文名……
后来干脆自己写了个 Mac 客户端，现在流程变成：
1️⃣ 直接输中文，精确匹配的排最前
2️⃣ 打错字也能救（rufuse → rufus）
3️⃣ 结果按做种数排，点一下复制磁力
搜索是本地服务跑的，只监听本机，不上传任何数据。
缺点也说：源连不上就搜不到，中文冷门片还是难。
（工具名在主页，Mac 12 以上可用）
```
**图**：3 张（搜索框 / 结果表 / 设置页），主图加一行字「打错字也能搜到」

## 笔记 2：教程型
**标题**：`Mac 装软件总提示"无法验证开发者"？两步解决`
```
右键 → 打开 → 再点「打开」
或终端：xattr -dr com.apple.quarantine /Applications/xxx.app
（顺便安利下我常用的磁力搜索客户端，主页有）
```

## 笔记 3：对比型
**标题**：`网页搜 vs 客户端搜，差多少？`
```
同一关键词「疯狂动物城」：
· 网页站：广告 3 个，结果 7 条，12 秒
· 客户端：结果 120 条，6 秒，精确命中排最前
差别主要在"多源聚合 + 本地服务"这两件事。
```

## 承接方式（三选一）
1. 主页简介写：`Mac 工具 → 私信「磁力」自动回复`
2. 置顶评论：「工具名在上图，主页有链接」
3. 建一个"工具合集"笔记，把下载页做成图片文字（不放二维码）
